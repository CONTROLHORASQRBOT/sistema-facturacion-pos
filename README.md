# 🧾 Sistema de Facturación POS Profesional

Sistema POS completo con doble caja, control de inventario, auditoría y facturación rápida. Desarrollado para negocios reales en Venezuela.

## 🚀 Características Principales
- ✅ Doble caja: Principal y Secundaria con arqueo automático
- ✅ Control de inventario en tiempo real con alertas de stock bajo
- ✅ Sistema de auditoría completo (quién hizo qué y cuándo)
- ✅ Roles y permisos: Administrador, Cajero, Auditor
- ✅ Facturación rápida con lector de código de barras
- ✅ Reportes de ventas, cierres de caja y ganancias
- ✅ Historial de movimientos y anulaciones con motivo

## 🛠️ Stack Tecnológico
- Backend: PHP 8 + MySQL
- Frontend: JavaScript, jQuery, Bootstrap 5
- Arquitectura: MVC
- Seguridad: Sesiones, encriptación, validación de roles

## 📦 Módulos Incluidos
- Ventas POS
- Inventario / Productos
- Clientes
- Caja y Arqueo
- Auditoría
- Reportes y Dashboard
